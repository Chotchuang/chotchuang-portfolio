Financial CRM & Portfolio Database

CS50 SQL final project — relational design for clients, investment orders, portfolio summaries, and loans.

Core entities

  • users — application operators
  • clients — customer records
  • stocks — tradable symbols
  • orders — buy/sell transactions
  • portfolios — aggregated holdings
  • loans — lending positions and status

Design choices

  • Primary and foreign keys on all relationships
  • Indexes on lookup columns used in dashboard queries
  • Views for portfolio summaries and lending exposure
  • Triggers to keep derived totals consistent

See the ER diagram in the work files for the full relationship map.
